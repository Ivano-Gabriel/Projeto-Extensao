# Validacao do prototipo de estudos

Esta pasta e independente do `apps/web` e do `apps/biblioteca`.
Rode na raiz do repositorio:

```bash
cd apps/estudos
npm ci
npm test
npm run build
npm run preview
```

Para testar offline, abra a URL do preview online pela primeira vez, escolha **Escola > Guardar para offline**, espere a confirmacao e depois marque **Offline** no DevTools do navegador. O cache nao e habilitado no `npm run dev`, porque isso confundiria demonstracoes de outros prototipos no mesmo localhost.

NUNCA use frequencia, notas, feed ou feedback desse prototipo como informacao real. Nao conecta ao banco.
